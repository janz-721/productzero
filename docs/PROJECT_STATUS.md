# ProductZero 项目状态

最后更新：2026-11-10

## 一句话介绍

ProductZero 是面向学生创业团队和独立开发者的 AI 产品发现与原型生成工作台，把模糊产品想法转化为带关键判断与依据、决策记录和可预览原型的 Product Brief。

## 当前模型策略

- 文本主模型：`glm-4-flash-250414`
- 文本备用模型：`glm-4.5-flash`、`glm-4.7-flash`
- 原型视觉主模型：`glm-4v-flash`，只生成紧凑界面蓝图，最大输出限制为 1024 tokens
- 原型视觉备用模型：`glm-4.6v-flash`、`glm-4.1v-thinking-flash`
- 服务器根据蓝图渲染完整 HTML，避免模型输出被截断或超过 Netlify 时长
- 视觉接口使用流式心跳，避免 Netlify 在模型处理期间触发无数据超时

## 数据和持久化

- 产品想法、当前访谈历史与最终回答暂存于浏览器 `localStorage`
- 刷新访谈页面后，会根据已保存的回答请求下一问
- 没有登录、数据库、团队协作和多项目管理
- 页面刷新后仍可能丢失尚未提交的输入内容和生成状态

## 密钥与安全

- `.env.local`：本地 API Key，已加入 `.gitignore`
- `netlify.env`：Netlify 导入配置，已加入 `.gitignore`

## 已知问题与风险

- 免费模型可能临时返回 429，需要重试或使用备用模型
- 每轮访谈都会调用一次模型，8 轮总耗时明显高于旧版固定流程
- 动态追问质量会随输入回答和模型状态波动；失败时会切换到对应的备用问题
- 确认理解会额外调用一次模型；若失败则保留原话作为临时整理内容，用户仍可手动修改并确认
- 视觉生成质量会随输入截图和模型状态波动
- Netlify 同步函数存在约 30 秒限制；原型当前约 15 秒，但仍需控制输入图片大小
- 单张参考图是当前 MVP 限制
- 服务端会拦截参考图中的旧业务文案并回退到当前产品文案
- 当前使用 Netlify 免费子域 productzero-demo.netlify.app，尚未绑定独立自定义域名
- 已有离线证据链回归脚本，但仍缺少真实模型接口回归、浏览器验收、单元测试与错误监控
- 新版 8 轮访谈、确认理解页面、Brief 长页面和视觉尚未完成桌面/手机浏览器截图验收
- 新版作品集截图尚未重新生成
- 已完成 3 人形成性测试，但仍是便利样本，不能作为定量效果或 PMF 证据
- 2/3 试用者指出 Product Brief 偏长、快速扫读困难，需要后续增加“一页速览 / 组员版”
- 反证问题对普通用户门槛偏高；频率问题需要支持“估算”和不确定性表达
- 需要区分“亲历、听说、观察”三类证据来源，避免把旁观观察误当成真实用户陈述
