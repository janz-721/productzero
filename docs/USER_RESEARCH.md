# ProductZero 用户试用记录

最后更新：2026-11-10

## 研究概况

- **研究目的**：验证普通用户能否独立完成 8 轮访谈、理解“确认理解”步骤，并判断生成的 Product Brief 是否可读、可核验。
- **样本规模**：3 名便利样本，非随机招募。
- **研究方式**：参与者自行完成 8 轮访谈，随后阅读确认内容与 Product Brief；反馈为自报。
- **完成情况**：3/3 完成 8 轮访谈；3/3 完成确认与文档阅读。
- **自报总用时**：50、67、50 分钟（中位数 50 分钟，平均约 56 分钟）。
- **继续使用意愿**：3/3 表示会继续使用，其中 1 人明确限定为前期发散，不把输出直接当作行动依据。


## 三位参与者


| 参与者                   | 背景                                         | 关键卡点                                                   | 保留原话                                           |
| ------------------------ | -------------------------------------------- | ---------------------------------------------------------- | -------------------------------------------------- |
| P01 竞赛小组负责人       | 需要把竞赛团队的想法理清楚                   | 频率问题只能估数；被问“什么情况说明想法不对”时卡最久     | “还没搞清楚要解决啥问题就先想做什么功能。”       |
| P02 社区面包店观察练习者 | 以观察到的店主情况作为输入                   | 担心把旁观观察当作真实用户陈述；工具列出的未知信息答不上来 | “线下聊天说得明白，写成线上文字就不敢写。”       |
| P03 网页原型产品新人     | 不会写前端代码，能画静态图但做不出可点击原型 | “什么情况证明我猜错”很难想；文档偏长，难以快速扫读       | “只能截图片放 PPT，讲的时候手动翻页假装能跳转。” |

## 汇总发现


| 发现                     | 证据                                     | 当前判断                                         |
| ------------------------ | ---------------------------------------- | ------------------------------------------------ |
| 原话可追溯是核心价值     | 3/3 主动提到保留原话，态度正面           | 必须保留，不应用整理内容覆盖原话                 |
| 流程可以完成，但成本偏高 | 3/3 完成；自报总用时 50–67 分钟         | 适合深度整理，不承诺“几分钟一键完成”           |
| 长文档难扫读             | P01 担心组员嫌字多；P03 明确说抓重点费劲 | 下一优先级是“一页速览 / 组员版摘要”            |
| 反证问题门槛高           | P01 卡最久；P03 明确说难想               | 需要示例、允许“我还没想到”，或改成更日常的追问 |
| 频率估算缺乏安全感       | P01 担心估高                             | 应允许标记“估算”，区分精确记录与主观估计       |
| 观察不等于访谈证据       | P02 担心脑补，并主动降低对输出的信任     | 应增加证据来源类型：亲历 / 听说 / 观察           |
| 输出完整不等于可行动     | P02 说不能直接动手，必须再找店主聊       | “下一步验证谁、问什么”应比更多结论更突出       |

## 下一步研究

1. 用当前版本重新测试 P03，确认口语化问题是否仍会卡住。
2. 增加“一页速览 / 组员阅读版”后，复测文档阅读时间与重点抓取情况。
3. 增加“亲历 / 听说 / 观察”来源标记后，复测 P02 的信任变化。
4. 让参与者现场完成一次“下一步找谁验证”的动作，而不是只评价文档。
